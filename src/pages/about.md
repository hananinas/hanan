I'm Hanan Choudhary Hadayat. I study Computer Science and Engineering at DTU and spend much of my time building software that I wish existed.

I work on [Elusive](https://elusivecph.com), a way to search for clothes across stores, and [Unravel Search](https://search.uai.dk), a search tool for AI agents. I've also worked on browser-testing tools and coding agents. The common thread is making complex tools easier to use without hiding how they work.

I'm developing a master's thesis topic around program analysis for oversight of coding agents. It's early work, and I expect the questions to change as I test them.

I write about projects as I build them. Older posts stay here so you can see the path, not just the current version.
